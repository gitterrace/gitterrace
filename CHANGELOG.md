# Changelog

All notable changes are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [0.1.0] - Unreleased

First public release.

- Browse any git repository in the browser, offline and read-only: code, commits, blame,
  branches, worktrees, stashes and live updates.
- Insights over history, cached in `.git/gitterrace/`.
- JSON API (`/api/v1`), a read-only MCP server, SVG cards and a year-in-review card.
- Optional user actions through `actions.toml`.
- Static export of a repository site.
